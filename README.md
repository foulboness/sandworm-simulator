# SANDWORM SIMULATOR

**A deep-dive into the mechanics, movement and engineering of a colossal subterranean creature.**

Sandworm Simulator is an interactive 3D simulation that brings a gigantic sandworm to life. Explore its anatomy, observe its movement beneath the desert, and experiment with its mechanical behaviour through an immersive simulation environment.

---

## Overview

What would it look like to observe a massive sandworm moving beneath kilometres of desert terrain?

This project explores that concept through a visually detailed, interactive simulator featuring procedural movement, segmented anatomy, underground navigation and real-time visualisation.

The experience combines computational animation, 3D graphics and interactive engineering-inspired controls to create a believable simulation of a colossal subterranean organism.

## Features

- **3D Sandworm Model** — A large, articulated creature with a detailed segmented body.
- **Procedural Movement** — Smooth, coordinated body movement and travelling contraction waves.
- **Underground Simulation** — Visualise the sandworm travelling beneath desert terrain.
- **Multiple Camera Views** — Observe the creature from different perspectives.
- **X-Ray Mode** — Reveal the internal structure and movement of the segmented body.
- **Real-Time Controls** — Experiment with movement, speed and simulation settings.
- **Surface Breach** — Watch the sandworm emerge through the desert surface.
- **Immersive Environment** — Atmospheric desert terrain, sand effects and cinematic lighting.

## Simulation Systems

| System | Description |
|---|---|
| Body Mechanics | Articulated segmented movement |
| Locomotion | Travelling contraction waves |

## Getting Started

### Prerequisites

- Node.js
- npm
- A modern web browser

### Installation

Clone the repository:

```bash
git clone https://github.com/foulboness/sandworm-simulator.git
```

Navigate into the project:

```bash
cd sandworm-simulator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
